📘 Open WebUI 教學：從安裝到進階應用


🚀 Open WebUI 安裝（Python 版本


1.安裝

pip install open-webui

2.啟動

open-webui serve

3.⚙️ 自訂 Port（預設為 8080）

open-webui serve --port your_port_number



🤖 串接 LLM 模型（以 Azure OpenAI 為例）


進入 Admin Panel 後，切換到 Settings → Connections（連線設定）



🧩 使用 Tools 串接自訂 API


Open WebUI 支援「Tools」功能，讓你可以將外部 API 服務整合進對話中，像是呼叫內部系統、查詢天氣或公司內部資料等

完成 Tool 建立後，只要在開始新對話時選擇對應模型，即可開啟或關閉你設計的 Tools



🔒 模型功能限縮與控制權限


✏️ 在模型設定中配置功能 前往 Models 頁面，點選欲設定的模型，在設定頁中可看到下方這些功能開關區域：
1) Tools：可勾選哪些外掛工具可用（如 APITEST）
2) Filters：可加入特定過濾器（如部門、權限邏輯等）
3) Knowledge：關聯特定知識庫
4) System Prompt：設定系統提示詞，可自訂角色、風格等
